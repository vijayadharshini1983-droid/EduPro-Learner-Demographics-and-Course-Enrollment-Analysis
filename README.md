 
# EduPro – Learner Demographics and Course Enrollment Behavior Analysis

## Project Overview

A data analytics project focused on exploring learner demographics and course enrollment behavior on the EduPro online learning platform. This project uses Python, Pandas, NumPy, Matplotlib, Seaborn, and Streamlit to analyze age groups, gender distribution, course category preferences, course levels, and enrollment patterns through Exploratory Data Analysis (EDA) and interactive visualizations.

## Objectives

- Analyze the age distribution of learners.
- Understand gender-wise enrollment patterns.
- Identify the most popular course categories.
- Analyze preferences for beginner, intermediate, and advanced courses.
- Explore enrollment behavior across different learner groups.
- Build an interactive Streamlit dashboard for data visualization.

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/your-username/EduPro-Learner-Demographics-and-Course-Enrollment-Analysis.git
```

Navigate to the project folder:

```bash
cd EduPro-Learner-Demographics-and-Course-Enrollment-Analysis
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
